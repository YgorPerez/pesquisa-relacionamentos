seo: { title: "Olhe para como a relação funciona, não só para a lista" }
---

Para saber se uma relação vai bem, olhe menos para a lista de qualidades do parceiro e mais para como vocês funcionam juntos: se você sente o compromisso do outro, se há apreciação, como vai o sexo e quanto vocês brigam. Em 43 estudos com casais, foi isso que melhor previu a satisfação. Os estudos acompanharam relações que já existiam, e nenhum estudo do acervo testou se escolher alguém por esse critério dá certo.
