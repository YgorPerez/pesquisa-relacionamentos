# Asking a round in text

For harnesses with no native question tool. Number each question and give your recommended answer:

```
❓ **Q1** - **<question title>**

<question body, might be multiple paragraphs>

- **(a)** <first option>
- **(b)** <second option>
- **(c)** <third option>

➡️ **(<letter>)** - <why you recommend it>

---

❓ **Q2** - **<question title>**

<question body, might be multiple paragraphs>

- **(a)** <first option>
- **(b)** <second option>

➡️ **(<letter>)** - <why you recommend it>
```

Every option is its own bullet, on its own line, opening with its bold letter, because the user answers by letter. Leave a blank line before the first bullet and after the last one, so the list renders as a list. A question with no options is fine: drop the bullets and answer it in prose.
